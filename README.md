Happiness es una aplicación de gestión de eventos desarrollada en Java con guardado de datos en MySQL. 
El sistema permite gestionar un catálogo de eventos, usuarios, galerías de imágenes y un sistema de favoritos, permitiendo intercacción.

Descripción del Proyecto:
La aplicación permite a los usuarios visualizar eventos programados, añadirlos a su lista de favoritos y acceder a galerías de imágenes de eventos pasados. 

Características principales:
Gestión de Usuarios: Creación o borrado de usuarios.
Catálogo de Eventos: Creación y borrado de eventos.
Sistema de Favoritos: Almacenar eventos favoritos de usuarios.
Galerías Multimedia: Asociación de imágenes a eventos.
Vistas SQL: Consultas sobre los datos registrados.
